# Shupscom Portfolio

A responsive, static portfolio website for Olasupo Kazeem Abolaji.

## Preview locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish to the existing GitHub Pages site
1. Download and extract this ZIP.
2. Open the repository that currently publishes `https://shupscom.github.io/` (usually `Shupscom/Shupscom.github.io`).
3. Back up or move the existing site files.
4. Copy `index.html`, `styles.css`, `script.js`, and the `assets` folder (if present) into the repository root.
5. Commit and push to the publishing branch (commonly `main`).
6. In GitHub, check **Settings → Pages** and confirm the publishing source points to the correct branch and root folder.
7. Allow GitHub Pages a few minutes to publish, then refresh the site.

## Before publishing
- Confirm the Sterling Bank dates (currently shown as March 2020–December 2021).
- Confirm the exact Tango implementation details and whether payment verification directly triggers dispensing or an operator confirms it.
- Add your LinkedIn profile URL (the current button is a generic LinkedIn destination).
- Add a downloadable, final PDF CV if you want a CV download button.
- Verify the Wallet API project status before presenting it as completed; this version labels it as in development.
- Review employer-approved wording for internal projects and remove any confidential implementation details.

## Notes
This is a static HTML/CSS/JavaScript site. It does not collect form submissions or require a backend.
